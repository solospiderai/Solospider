Sitemap discovery logic
Try: GET /sitemap.xml (most common)
If 404 → try: GET /sitemap_index.xml
If 404 → try: GET /robots.txt → look for "Sitemap:" directive
If 404 → fallback: crawl homepage + extract <nav> href links
If sitemap_index → fetch each child sitemap recursively
If sitemap has >500 URLs → sort by priority + lastmod DESC, take top 500
URL filtering rules
EXCLUDE: *.jpg, *.png, *.pdf, *.css, *.js, *.xml
EXCLUDE: /wp-admin/, /wp-login/, /.well-known/
EXCLUDE: ?utm_*, ?ref=*, ?fbclid=* (tracking params)
EXCLUDE: /feed/, /rss/, /amp/ (non-canonical)
EXCLUDE: URLs from different domain (misconfig check)
Per-page error handling
HTTP 200 → crawl and extract content ✓
HTTP 301/302 → follow redirect (max 3 hops)
HTTP 403 → mark crawl_status: blocked; surface in UI
HTTP 404 → mark crawl_status: failed; surface as crawl issue
HTTP 429 → back off 30s, retry once; then mark failed
Timeout (>10s) → retry once after 30s; then mark failed
JS-heavy page → Playwright renders JS before extract
robots.txt Disallow → respect; skip URL; flag in UI
LLM topic extraction output
